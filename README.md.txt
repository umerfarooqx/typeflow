# TypeFlow — Typing Tutor

A comprehensive, offline-capable typing tutor with:
- 9 practice modes (time, words, quote, code, numbers, symbols, zen, drill, custom)
- 10 preset themes + custom theme builder
- Font, caret, layout, and effect customization
- Full stats: WPM, accuracy, consistency, heatmaps, bigrams, history
- **Adaptive/smart content** — weak-key drills, weighted word pools, spaced repetition
- Content library with 19 packs (words, quotes, code, literature, drills…)
- Installable PWA with offline caching
